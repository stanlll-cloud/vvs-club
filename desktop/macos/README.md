# vvs-club Mac 应用

同一窗口里，左侧选择入口，右侧浏览网页。在线站点各自保留页面，切换时无需重新打开首页；后退、前进与刷新只作用于当前站点。页面会使用 macOS WebKit，使用体验取决于网站对 Safari/WebKit 的支持。

## 构建与打开

需要 macOS 13 或更新版本，以及 Apple Command Line Tools。在仓库根目录执行：

```sh
python3 desktop/macos/build.py
```

构建结果是 `build/vvs-club-macos/vvs-club.app`，按当前 Mac 架构生成。此包使用本地签名，没有 Apple Developer ID 签名或公证；跨机器分发需要单独准备签名与兼容性验证。

## 在线影视区

入口由 [sites.json](sites.json) 维护，每个项目包含 `name` 和 HTTPS `url`。当前包含使用者指定的 PigAV、JAVHDPorn、SpankBang、Pornhub 中文站、MissAV（中文与英文版）、Jable 和 xHamster。修改后重新构建即可。站点之间不复用应用的访问密码，也不会从系统浏览器导入登录信息。

右侧是独立的顶层 `WKWebView`，没有使用 iframe，也不移除网站响应头、修改证书信任或代理网站内容。网站的登录、年龄、地区与访问验证仍由使用者在原站完成。自动弹窗不启用；新窗口链接由默认浏览器打开。站点若不兼容，可使用工具栏的外部打开按钮。

应用不提供视频资源、不解析真实播放地址、不绕过会员或 DRM，也不保证第三方站点始终可访问或可播放。网站无法连接时显示失败提示；主界面不自动打开任何在线站点。

## 可视化扫描与网盘

左侧「扫描本地」打开系统文件夹选择器；选好后，右侧的首次设置或媒体目录表单会预填该文件夹，使用者确认并保存后再开始扫描。

「连接网盘」提供百度网盘、阿里网盘、夸克网盘、TeraBox 和 115 网盘的选项。当前实现是同步／挂载文件夹接入，使用者需先用相应客户端或已有挂载工具，让网盘目录在 Finder 中可读取。这里没有实现这些服务的账号 API 直连、扫码登录或网页登录后自动取得文件列表。网盘目录按可能计费的读取来源处理，由使用者确认策略。

## 本地媒体库

此源码版构建时记录当前仓库位置；需要先按锁文件准备该目录的 `.venv`。选择「本地媒体库」时，应用启动自身管理的媒体服务，只监听回环地址，不接管其他服务。首次运行进入设置页，选择媒体目录并保存后重载配置。应用关闭时只停止它创建的服务；媒体和数据保留。

数据默认位于用户的 `Library/Application Support/vvs-club/media-data`，日志在同级 `logs` 目录。扫描、补全、播放、标签与收藏等能力使用完整的 Peach 后台。FFmpeg 与采集工具仍按上游机制准备。当前包不包含独立 Python 运行时，不能仅复制 `.app` 到另一台 Mac；可移植安装包尚未完成。

已有服务的连接地址入口移到应用菜单「高级：连接其他媒体服务」，主侧栏不要求填写 IP。源代码目录与 `.venv` 必须保留；若移动源码，应重新构建应用。

账户、Cookie 和站点数据由系统 WebKit 的应用数据存储管理。不要把登录信息、个人媒体或数据库放进仓库。

## 外观

影院式布局提供深色和浅色两套外观。点击右上角太阳／月亮按钮切换，选择保存在本机。侧栏、工具条与网盘入口使用带边缘高光的玻璃材质；自有媒体页同步主题，第三方站点保留自身外观。

Logo 同时用于侧栏、欢迎页与应用图标。侧栏底部的 Just My Socks 按钮是维护者的推广入口，使用默认浏览器打开；不会自动注册、购买或更改网络设置。

## 网盘账号登录

主连接页已改为账号授权，文件夹选择位于高级入口。当前支持范围、验证状态、OpenList 授权服务、网络路径和许可见 [网盘账号连接](CLOUD_CONNECTIONS.md)。

## 书签

在线站点顶部星形按钮可一键收藏当前网页，已收藏时星形填满。左侧「在线影视区 → 书签」可双击打开、编辑名称和网址、创建多层文件夹，并拖拽排序或移入文件夹；「移动到」提供不拖拽的替代操作。选中文件夹后创建文件夹即创建子文件夹。删除可撤销最近一次操作。书签保存在本机应用数据目录的 bookmarks.json，不上传 GitHub。

## 广告拦截

在线网站默认启用内置 WebKit 内容拦截：阻断随包规则列出的常见广告域名、隐藏常见广告容器，并抑制新窗口弹出。顶部盾牌按钮可关闭或重新开启，开关会保存，点击后刷新当前网站。影响范围为所有在线站点；本地媒体库和网盘授权窗口不加载这些规则。规则离线随版本更新，不上传浏览记录，不修改系统代理。规则是精简覆盖，不能保证拦截所有广告；遇到播放或网页功能异常可先关闭盾牌后刷新。在线站点的新窗口始终不交给系统浏览器：同站及已登记的站点子域名在当前页面打开，跨站弹窗直接拦截。这个弹窗策略不随广告规则开关关闭；只有顶部「在默认浏览器打开」按钮会主动外跳。

实现依据：[Apple WebKit 内容规则](https://developer.apple.com/documentation/webkit/wkcontentruleliststore)。

侧栏广告位使用选取自 EasyList 的站点专用隐藏规则，只隐藏已知广告容器，不整栏隐藏推荐视频。规则来源、版本与 CC BY-SA 3.0 许可见 [EasyList 声明](../../resources/third-party/EasyList-NOTICE.txt)。

右上角「×」关闭本窗口中的所有在线网页和本地媒体页面，停止播放并回到初始首页；它不退出软件，也不清除书签和网站登录数据。后台网盘扫描不因返回首页而取消。

进入本地媒体库时采用独立视图，隐藏在线站点侧栏和浏览器工具栏，媒体库占满内容区域。窗口标题栏的「返回主界面」可退出媒体库并恢复外层导航。媒体库原有刮削、资料补全、封面和字幕功能不因视图切换而删减。

外层导航与 Mac 媒体库使用统一的系统字体、16 号导航文字、玻璃选中态及深浅色配色；外层侧栏可滚动。底部推广区显示「搬瓦工机场」「3网GIA 线路直连」与加大的开通按钮。

网站验证页持续停留时，应用会在页面载入约 20 秒后提示手动重试、关闭广告规则后重试或主动使用默认浏览器。Cloudflare 验证资源不纳入广告拦截；应用不点击或绕过验证码，不伪装浏览器、不转移验证 Cookie。内置 WebView 是否可完成验证由网站及验证服务决定，无法保证兼容；参考 [Cloudflare 支持的浏览器](https://developers.cloudflare.com/cloudflare-challenges/reference/supported-browsers/)。
