# 网盘账号连接

「连接网盘」的主要入口是账号登录，不再弹出电脑文件夹选择器。选择百度、阿里或 115 后，点「登录并授权」打开相应网盘的登录页面。授权成功后，程序通过 OpenList 读取一次云端文件列表；只有读取成功才显示已连接。

接着选择盘内目录，点击「扫描这个目录」。扫描递归读取文件名、目录和大小，识别视频扩展名，不自动下载整部影片。结果支持在连接页播放；「加入本地媒体库」为已发现的影片生成本机 STRM 索引，带入媒体库设置，确认后才入库。STRM 播放需要本机网盘连接组件运行。

## 当前边界

- 百度、阿里、115 已接入登录回调、目录读取、扫描和播放代理代码，115 已由使用者完成授权并验证文件列表；百度、阿里仍待实际账号验证，扫描和播放仍需实际验证。不能以构建或未授权页面代替验收。
- 夸克与 TeraBox 仍显示「暂未接通」，不提供假登录或假扫描结果。
- 原来的同步／挂载文件夹模式保留在高级入口。
- 目前源码版仍依赖构建时源码目录及 `.venv`；不是跨机器便携发行版。

## 授权与网络

使用 OpenList 提供的应用参数时，部分授权和令牌刷新经 `https://api.oplist.org` 处理。登录窗口不导入系统浏览器 Cookie，不自动填写账号密码，也不替使用者确认平台条款或授权。平台的实际授权权限以登录页面为准；连接组件可能持有平台授予的读写权限，本页面不提供云端改名、移动或删除操作。

文件列表、扫描和视频流由使用者自己的电脑联网读取，不经过 vvs-club 维护者的服务器。应用不改变代理或 VPN 配置，网络速度和可访问性仍受当前网络及网盘规则影响。

本机组件仅监听 `127.0.0.1`，管理令牌不发给网页；连接桥接口需要仅在应用内传递的随机能力值。组件数据与授权数据库放在本机应用数据目录，目录权限为仅当前用户可访问，不上传到 GitHub。STRM 含本机播放能力地址，应作为私有索引保存。
